# Nord Stage 4 說明書繁體中文翻譯

本專案旨在將 Nord Stage 4 說明書（版本 1.4）翻譯為繁體中文，供 Nord Stage 4 88 使用者及其他同系列機型使用者參考，協助理解樂器的功能、操作方式與各項設定。

目前已完成第一輪翻譯，後續將對照原文進行校對，確認內容完整性、操作說明的準確性，以及專有名詞與用語的一致性。

## 專案內容

- `Nord.pdf`：原文說明書。
- `src/`：第一輪中英雙語譯稿，包含 13 章、附錄及章節圖片。
- `src/SUMMARY.md`：章節目錄。
