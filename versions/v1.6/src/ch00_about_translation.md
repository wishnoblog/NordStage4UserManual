# CH0：關於翻譯資訊

## 翻譯目的

本書以 Nord Stage 4 說明書 OS 1.6x（Edition N）為基礎，提供繁體中文與英文對照內容，協助 Nord Stage 4 88 及其他同系列機型的使用者理解樂器功能、操作方式與各項設定，作為學習與日常操作的參考。

## 翻譯進度

本版由 1.4x 譯稿逐章對照 OS 1.6x Edition N 更新，已補上音高與精細調音、Morph 踏板控制、全域殘響位置，以及 TP-1／TP-2 設定差異。後續將持續對照原文校對，確認內容完整性、操作說明的準確性，以及專有名詞與用語的一致性。

## 閱讀與版本說明

本書採中英雙語對照，方便閱讀與核對原文。實際功能與操作可能因樂器系統版本而有所差異，請配合所使用機型與系統版本閱讀。

本翻譯為非官方中文參考資料。產品名稱、商標及原文說明書的相關權利歸原權利人所有；如譯文與原文有差異，請以原文說明書為準。

## 1.6x 更新重點

- 新增合成器音高與精細調音說明（原文第 28 頁）。
- 補充 TP-2 左／中踏板的 Control 與 Morph 功能（第 38、60、66 頁）。
- 說明全域殘響位於旋轉喇叭與音層音量推桿之後（第 52–53 頁）。
- 更新 Nord EP 踏板類型與預設值，分開說明 TP-1／TP-2（第 60 頁）。
- 原文 Panel Assigned／User Assigned 的名稱差異保留於 CH11 註記。
