# OS 1.6x 更新重點

本版以 **Nord Stage 4 User Manual v1.6x，Edition N** 為依據，由 1.4x 譯稿逐章對照更新。這裡列出手冊新增或調整的說明，不代表所有功能均於 OS 1.6 首次推出。

| 章節 | 更新內容 |
| --- | --- |
| [CH6 合成器](ch06_synth_section.md) | 新增音高與精細調音：音高範圍為 −24 至 +24 個半音，精細調音範圍為 ±50 音分。 |
| [CH7 音色配置管理](ch07_program.md) | 補充 TP-2 左／中踏板設為 Control 時，可像控制踏板一樣控制 Morph。 |
| [CH9 音層效果](ch09_layer_effects.md) | 補充全域殘響位於旋轉喇叭及各音層音量推桿之後，並釐清旋轉喇叭與殘響的訊號順序。 |
| [CH11 選單設定](ch11_menus.md) | 更新 Nord EP 類型與預設值，補上 EP15／EP30，分開說明 TP-1 與 TP-2；保留原文 Panel Assigned／User Assigned 名稱差異的註記。 |
| [附錄](appendix.md) | 補充 TP-2 Control 功能與接線說明。 |

各章局部圖示與整頁參考圖已改用 1.6x PDF，並更新章節交叉引用。專有名詞沿用譯者在 Excel 中的定案；空白項目採用先前的建議譯法。

頁面上方可切換 **OS 1.4x／Edition L** 與 **OS 1.6x／Edition N**。切換時會保留目前章節；1.4x 保留原版內容，供舊系統使用者參考。
